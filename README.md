# Система учёта комп.техники TECH.REC

Репозиторий содержит исходный код трех компонентов системы. 
**Для быстрой проверки без компиляции кода:** Скачайте готовый архив в блоке **Releases** (справа), где находятся уже собранные приложения и конфигурационные файлы.

## 🚀 ИНСТРУКЦИЯ ПО РАЗВЕРТЫВАНИЮ (Для работы на разных ПК)

### Шаг 1. Настройка сети (Radmin VPN)
1. Установите [Radmin VPN](https://radmin-vpn.com) на ПК Администратора и ПК Студента.
2. **На ПК Администратора:** Нажмите «Создать сеть», введите имя и пароль.
3. **На ПК Студента:** Нажмите «Присоединиться к сети», введите данные сети.
4. **Важно:** На ПК Студента в окне Radmin VPN скопируйте IP-адрес Администратора (например, `26.x.x.x`).

### Шаг 2. Развертывание БД (На ПК Администратора)
1. В папке `database` запустите установщик `SQL2022-SSEI-Expr.exe`.
2. В появившемся окне выберите **Пользовательский (Custom)** тип установки. Нажмите «Установить» для скачивания мастера.
3. В открывшемся Центре установки SQL Server выберите самый первый верхний пункт: *«Новая установка изолированного экземпляра SQL Server...»*.
4. Нажимайте «Далее» (Next), со всем соглашаясь, пока не дойдете до шага **Настройка компонента Database Engine** (Database Engine Configuration).
5. На вкладке *Server Configuration* в блоке *Authentication Mode* переставьте точку на **Смешанный режим (Mixed Mode)**.
6. В поле ввода пароля для учетной записи администратора (`sa`) задайте: `12345`.
7. **Обязательно:** Чуть ниже в этом же окне нажмите кнопку **«Добавить текущего пользователя» (Add Current User)**, чтобы ваша Windows-учетка тоже стала админом БД. Завершите установку.
8. Откройте встроенную утилиту *SQL Server Configuration Manager* -> перейдите в *SQL Server Network Configuration* -> *Protocols for SQLEXPRESS* (или MSSQLSERVER) -> Нажмите правой кнопкой на **TCP/IP** и выберите **Включить (Enabled)**. В свойствах TCP/IP на вкладке *IP Addresses* прокрутите в самый вниз и в поле *TCP Port* убедитесь, что стоит `1433`. Перезапустите службу SQL Server.
9. Откройте ваш SQL-скрипт `database/init_with_data.sql` через любой удобный инструмент (например, блокнот, dbeaver, или выполните через командную строку с помощью утилиты sqlcmd: `sqlcmd -S localhost\SQLEXPRESS -U sa -P 12345 -i init_with_data.sql`), чтобы автоматически создать базу данных `CourseworkPractice` со всеми таблицами и готовыми тестовыми данными.


### Шаг 3. Конфигурация и Запуск

#### 🖥️ НА СТОРОНЕ АДМИНИСТРАТОРА:
1. Запустите проект **TechnicAcounting_API** (серверное приложение).
2. В файле `appsettings.json` для TechnicAcounting_API строка подключения должна смотреть на локальную базу:
   `"Server=localhost;Database=CourseworkPractice;User Id=sa;Password=12345;..."`

#### 🎓 НА СТОРОНЕ СТУДЕНТА (КЛИЕНТ):
1. Перенесите файлы скомпилированного клиента на второй ПК.
2. Откройте файл `appsettings.json` рядом с клиентом через Блокнот.
3. В строке подключения к БД и в адресе API замените `localhost` на скопированный IP-адрес Администратора из Radmin VPN:
   ```json
   {
     "ConnectionStrings": {
       "DefaultConnection": "Server=IP_АДМИНИСТРАТОРА,1433;Database=CourseworkPractice;User ID=sa;Password=12345;TrustServerCertificate=True;"
     },
     "ApiSettings": {
       "BaseAddress": "http://IP_АДМИНИСТРАТОРА:5123/"
     }
   }
   ```
4. Запустите клиентское приложение.
